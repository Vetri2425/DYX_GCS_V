                              AFFINE MATH (FOR REFERENCE)
═════════════════════════════════════════════════════════════════════════════════

IF APP DOESN'T AUTO-CALCULATE, USE THESE FORMULAS:

SCALE = GPS_distance / CAD_distance
ROTATION = GPS_bearing - CAD_angle

For any point (x_cad, y_cad):
  x_rotated = (x_cad - x_origin) × SCALE × cos(ROTATION) - ... × sin(ROTATION)
  y_rotated = (x_cad - x_origin) × SCALE × sin(ROTATION) + ... × cos(ROTATION)
  
  lat_gps = lat_origin + (y_rotated / 111000)
  lon_gps = lon_origin + (x_rotated / 111000 × cos(lat_origin))

                                  TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM                          → SOLUTION
─────────────────────────────────────────────────────────────────────────────────
GPS won't lock                   → Move outside. Wait 30s. Use high-accuracy.
DXF won't load                   → Ensure DXF is 2013+ format. Test simple rect.
Points look wrong                → Verify SAME corners in GPS & CAD (⚠️ crucial!)
Transform seems rotated          → Check bearing calculation. Verify CAD orient.
Waypoints too sparse             → Ask for denser DXF. Post-process in app.
Rover drifts off path            → Reduce WP_RADIUS to 0.2m. Slow speed 0.3m/s.
GPS lost during execution        → RTK fallback to standard GPS. Still ±5m accurate.
